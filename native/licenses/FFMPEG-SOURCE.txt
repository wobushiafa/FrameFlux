cross-compiled with aarch64-linux-gnu GCC 15 and the Debian
libc6-arm64-cross/libc6-dev-arm64-cross 2.36-8cross1 sysroot.
Configuration: --target-os=linux --arch=aarch64 --enable-cross-compile
--cross-prefix=aarch64-linux-gnu- --enable-shared --disable-static --enable-version3
--disable-programs --disable-doc --disable-debug --disable-autodetect.
Build with make, then use the six versioned FFmpeg shared libraries from the build.
This ARM64 build uses FFmpeg's software decoders and has no VAAPI or platform-specific
hardware acceleration enabled.
The Android builder has local changes recorded in FFMPEG-KIT-NEXT-LOCAL.patch. Apply with git apply --unidiff-zero.
The included FFmpeg libraries are LGPLv3. FFmpegKitNext uses --enable-version3 and does not enable --enable-gpl by default.
Every native package includes the corresponding FFmpeg source archive under source.
The Android package also includes FFmpegKitNext and cpu_features source archives,
build scripts, local patches, and the cpu_features Apache 2.0 license.

Windows x64 build: FFmpeg source tag n9.0.1, commit
bf1b838f2ab88b4f8fd83443325c782ea0e0f7fa from https://github.com/arthenica/FFmpeg.
The FFmpeg libraries are built directly, without the FFmpegKit wrapper or patches.
Build recipe: native/build/windows/Dockerfile and native/build/windows/README.md
(included in the Windows NuGet package under source-build/windows).
Toolchain: Ubuntu 24.04 MinGW-w64 GCC 13.2.0, MinGW-w64 headers 11.0.1, NASM 2.16.01.
Configuration: --prefix=/out --target-os=mingw32 --arch=x86_64 --enable-cross-compile
--cross-prefix=x86_64-w64-mingw32- --cc=x86_64-w64-mingw32-gcc-posix
--enable-shared --disable-static --enable-version3 --disable-programs --disable-doc
--disable-debug --disable-avdevice --disable-autodetect --enable-w32threads
--enable-network --enable-d3d11va --enable-dxva2 --enable-schannel
--extra-ldflags=-static-libgcc.
Before make, prepend -L/static-runtime to ffbuild/config.mak LDFLAGS, with
libwinpthread.a and its libpthread.a alias from the MinGW toolchain staged in
/static-runtime. This links
MinGW's clock_gettime/nanosleep support statically without an extra runtime DLL.
No --enable-gpl or --enable-nonfree is used; the Windows DLLs are LGPLv3-or-later.
